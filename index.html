Harper CalendarSyncGOOGLE CALENDAR SYNC TOOL

Harper CalendarSync is a personal, non-commercial utility that uses the Google Calendar API to read and create calendar events on the user's own Google account. It is used by a single individual for private scheduling and is not offered, promoted, or made available to the public.

What it does

  • Reads the user's own Google Calendar entries
  • Creates and verifies calendar events on that same account
  • Stores its OAuth credentials locally on the user's own device

What it does not do

  • Does not collect, sell, or transmit data to any third party
  • Does not run a server-side database of calendar data
  • Does not have other users — access is limited to the account owner
